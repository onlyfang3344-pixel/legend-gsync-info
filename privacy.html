隐私政策

适用应用：Legend Obsidian GSync。更新日期：2026年11月19日。

使用范围

此 OAuth 应用由应用所有者个人使用，用于个人笔记、文档与 Google Drive 文件同步，不提供公众服务，不收集其他用户注册资料。

访问和使用的数据

同步程序访问 Google Drive 的文件名称、标识、目录结构、大小、修改时间、校验信息及待同步文件正文。上述数据用于定位目录、比较文件、上传、下载及验证同步结果。GSync 启用删除同步时会处理对应文件的回收站操作。

Google 授权范围为完整 Drive 权限；应用按配置目录执行同步，但该目录限制由程序实现，不会缩小授权令牌本身的权限。

存储与传输

笔记及日报保存在本人控制的设备和 Google Drive 的配置目录中。OAuth 客户端配置及刷新令牌保存在使用该应用的设备上，访问令牌在同步时用于向 Google API 发起请求。文件同步程序及 GSync 插件会保存必要的同步状态或校验记录。

默认 GSync 登录流程会经插件作者托管的静态回调页返回一次性授权码，再交回 Obsidian；GSync 使用 PKCE 保护此流程。回调页的具体实现由插件作者维护。此说明页面自身不接收授权码、令牌或笔记内容。

这两页说明由 GitHub Pages 托管。页面没有自行部署的分析脚本、广告、表单或 Cookie；GitHub 可能按其隐私声明记录访问 IP 等安全日志，详见 GitHub 隐私声明。

共享与使用限制

此同步用途不出售 Google 用户数据，不将其用于广告投放或通用 AI 模型训练。除履行用户选择的 Google Drive 同步及运行所需的服务处理外，不为此同步功能向第三方提供笔记正文或授权令牌。其他独立 AI 分析工具不属于此 OAuth 同步应用。

本应用对从 Google API 获取的信息的使用和转移遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

保留与撤销

同步文件按个人选择保留。所有者可在 Google 账号的第三方访问权限页面撤销应用授权，并在对应设备 删除不再需要的凭证。撤销授权不自动删除设备或 Google Drive 的文件副本。文件可由所有者分别在对应存储位置管理。
